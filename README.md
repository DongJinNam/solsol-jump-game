# 솔솔바람 점프

별을 모으고 장애물을 피하며 몽글이의 퀴즈를 통과하는 브라우저 게임입니다.
화면 터치 또는 `Space` / `↑`로 점프하고, 공중에서 한 번 더 점프할 수 있습니다.

먼저 이름(별명)을 입력하면 게임 안내가 나타납니다. 완주 화면에는 입력한 이름이 표시됩니다.
속도는 중간 / 빠름 두 단계이며, 높이 쌓인 2단 약병은 이중점프로 넘습니다.
진행률 25%, 50%, 75%에서 솔솔바람 지원 범위·가족 지원·이용 시기 퀴즈를 풉니다.
오답 후에는 설명을 읽고 다른 선택지로 재도전할 수 있습니다.

점수는 100점에서 시작합니다. 놓친 별마다 `100 / 전체 별 수`점(현재 42개),
퀴즈 오답 선택마다 5점을 차감하며, 최저 0점이고 소수점 첫째 자리까지 표시합니다.
계산은 반올림 전 값으로 누적해 별을 모두 놓치면 정확히 100점이 차감됩니다.
게임 종료 시 남은 별도 미획득으로 계산합니다. 재도전하면 점수와 감점이 초기화되며
이름과 선택한 속도는 유지됩니다. 이름은 현재 페이지에서만 사용하며 전송·저장하지 않습니다.

## 로컬 기동

Node.js 22 이상과 npm이 필요합니다. 외부 의존성이 없어 `npm install`은 필요하지 않습니다.
저장소 루트에서 실행합니다. Windows PowerShell에서도 동일합니다.

```sh
node --version
npm run dev
```

`npm run serve`로도 동일하게 실행할 수 있습니다. 원본 파일을 제공하므로 사전 빌드는 필요하지 않습니다.

[http://127.0.0.1:5173/](http://127.0.0.1:5173/)에서 게임을 엽니다.
파일 변경 후 브라우저를 새로고침하면 반영됩니다. 자동 새로고침은 제공하지 않습니다.
서버 종료는 `Ctrl+C`입니다. 포트가 사용 중이면 `npm run dev -- --port 5174`를 사용하세요.
PowerShell에서 `npm.ps1` 실행 정책 오류가 나면 `npm` 대신 `npm.cmd`를 사용합니다.
ES 모듈을 사용하므로 HTML 더블클릭(`file://`) 대신 HTTP 서버를 이용해야 합니다.

## 빌드와 빌드 결과 실행

```sh
npm test
npm run build
npm run preview
```

빌드는 HTML, `src/`, `styles/`, `assets/`를 `dist/`에 복사합니다.
별도 번들링이나 압축 없이 브라우저의 기본 ES 모듈을 사용합니다.
정적 호스팅용 `dist/index.html`도 생성합니다. 배포할 때는 **HTML 하나가 아닌 `dist/` 전체**를 올립니다.
`dist/`는 Git에서 제외됩니다.

미리보기 역시 기본 5173 포트를 사용합니다. 개발 서버를 종료하거나 다른 포트를 지정하세요.

```sh
npm run preview -- --port 5174
```

원본 수정 후에는 다시 빌드해야 미리보기에 반영됩니다.
파일을 삭제·이름 변경한 경우 이전 빌드 파일이 남을 수 있으므로 `dist/`를 비우고 다시 빌드하세요.

화면 컴포넌트는 전달받은 상태를 표시하고, 보상과 진행 여부는 컨트롤러가 결정합니다.
렌더러는 게임 상태를 변경하지 않습니다. 레벨 생성과 충돌 판정은 DOM 없이 사용할 수 있습니다.

## 검증

`npm test`는 점수 유지, 오답 후 재도전, 피격 보호, 속도별 점프·별 획득,
퀴즈 3회 통과·완주, 재시작을 검증합니다. 테스트는 실제 게임 로직을 격리된 VM에서 실행하고
DOM/Canvas만 대체합니다. 테스트 로더는 ESM 문법을 VM용으로 변환하므로
실제 브라우저의 모듈 로딩과 화면 배치는 별도로 확인해야 합니다.

화면 수정 후에는 개발·미리보기 서버에서 다음 항목을 확인하세요.

- 시작, 점프·이중점프, 속도 선택, 일시정지
- 퀴즈 오답 → 다른 답 → 정답 → 게임 재개
- 성공 화면 캡처 안내와 다시 도전
- 작은 모바일 화면과 창 크기 변경

`agent_refer/`의 개선 제안은 참고 문서이며, 현재 규칙은 위 설명과 실제 게임 코드를 기준으로 합니다.
